## 一、范围界定

### 必须交付(v0.1.0)

1. **记录存储**:`rows` 槽位 + `gens` 代际 + `free` 空闲栈 + `order` 插入序。
2. **三类索引**:唯一 / 非唯一 / 有序(`SortedMap`)。
3. **四类写入**:`insert` / `update` / `remove` / `clear`,冲突**不静默覆盖**。
4. **四类查询**:`get` / `get_by` / `iter_by` / `range_by` + `iter`(插入序)。
5. **公开自检**:`verify_invariants()`(I1–I8)。
6. **JSON 往返**。
7. **工程面**:对拍测试、QuickCheck、基准、三平台 CI、README + 示例。

### 明确不做(见 SPEC §11)

持久化 RowId、并发安全、磁盘存储、复合/表达式索引。

| # | 里程碑 | 内容 | 出口条件 |

## 四、风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 不变量在某条删除路径上失配 | 高 | 对拍 + 每步 `check_invariants`(bimap 的经验:删除是最易错路径) |
| 有序索引与哈希索引的键类型统一带来约束膨胀 | 中 | 约束按方法最小化;必要时 `register_sorted` 单独要求 `K : Compare` |
| 参考实现语义与直觉冲突 | 中 | SPEC §0 先锁定;冲突时选"更简单、更可测试"的一侧并记 CHANGELOG |
| 18 天内完成度不足 | 中 | 按 M1–M7 小步提交,任何时刻仓库都处于可验收状态 |
| 被质疑与 slotmap / IndexMap 重复 | 低 | README 与申报书已备好对照表(SPEC §1) |
