## 一、与参考实现的关系:**不是移植**

> 回答"我们是不是把 Rust `multi_index_map` 移植过来" —— **不是。**

`multi_index_map`(MIT)与本库共享**同一个架构想法**(记录表 + 每个索引字段一张查找表),
但**没有一行代码可以照搬**,因为两侧的底层设施根本不同:

| 维度 | 参考实现(Rust) | 本库(MoonBit) | 结论 |
|---|---|---|---|
| 索引定义 | `#[derive(MultiIndexMap)]` **过程宏**,编译期生成类型与方法 | MoonBit **没有过程宏**;运行时闭包注册 `register_*(name, (V) -> K)` | 机制**重新发明** |
| 记录存储 | `slab::Slab<T>`(无代际号,槽位 LIFO 复用) | `Array[V?]` + `gens` + `free`,自研 | 重新实现 |
| 句柄 | 裸 `usize` 槽下标(陈旧即 ABA) | `RowId{slot, gen}` + 溢出退役槽位(I9) | **新增概念** |
| 更新协议 | `update_by_*`(仅未索引字段)+ `modify_by_*`(整条);冲突时**先删旧键再插新键,失败即 panic** | 只有 `modify`,**先全量预检再一次性提交** | **必须重新设计**(上游行为是缺陷) |
| 范围查询 | **无**(ordered 索引只暴露点查与全量遍历) | `range_by` / `range_inclusive_by` / `iter_asc_by` / `iter_desc_by` | **新增能力** |
| 泛型查询 | `&Q where Field: Borrow<Q>`(可用 `&str` 查 `String` 键) | MoonBit 无 `Borrow`,键类型显式 | API 形态重构 |
| 可变投影 | `get_mut_by_*` 返回元素内字段的 `&mut` | MoonBit 无法返回元素内的 `&mut` 投影 | API 形态重构 |

**结论**:本项目在申报口径上是**原创**,不是**移植**。参考的是设计思想与 API 形态
(思想、算法、数据结构不受版权保护),实现全部以 MoonBit 惯用法自写;
来源、许可证与参考范围仍按合规要求在 [`NOTICE`](../NOTICE) 逐条登记。

> **边界纪律**:如果某个改动退化成"照着 `generators.rs` 翻译",那就是走错了路 ——
> 应当先在 [`SPEC.md`](../SPEC.md) 里写清 **MoonBit 侧**的设计,再动手实现。

## 二、范围界定

### 必须交付(v0.1.0)

1. **记录存储**:`rows` 槽位 + `gens` 代际 + `free` 空闲栈 + `order` 插入序。
2. **四象限索引**(唯一性 × 有序性):哈希唯一 / 有序唯一 / 哈希非唯一 / 有序非唯一。
3. **写入**:`insert` / `insert_many` / `update` / `modify` / `remove` / `clear`,冲突**不静默覆盖且归还记录**。
4. **查询**:`get` / `get_by` / `iter_by` / `range_by` / `range_inclusive_by` / `iter_asc_by` / `iter_desc_by` / `iter`(插入序)。
5. **公开自检**:`verify_invariants()`(I1–I9)+ `index_stats`。
6. **JSON 往返**。
7. **工程面**:对拍测试、QuickCheck、差分夹具、基准、三平台 CI、README + 可运行示例。

### 明确不做(见 [SPEC §11](../SPEC.md))

持久化 `RowId`、并发安全、磁盘存储、复合/表达式索引;`insert_or_replace` 与 schema 代码生成器列入 v0.2 候选。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 不变量在某条删除/更新路径上失配(bimap 的经验:删除最易错) | 对拍 + 每个操作后 `check_invariants`;先写测试再改实现 |

| 参考实现语义与直觉冲突 | 以 [SPEC §0](../SPEC.md) 的裁定为准;冲突时选"更简单、更可测试"的一侧并记 CHANGELOG |

| 被质疑与 slotmap / IndexMap 重复 | README 与申报书备有对照表(SPEC §1);本期新增工作有 commit 记录可追踪 |
