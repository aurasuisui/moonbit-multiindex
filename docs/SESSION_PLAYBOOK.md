# SESSION_PLAYBOOK.md — 任务会话手册(讨论方案 → 执行)

> **读者**:为本仓库开的一个**新会话**,来做一件具体的事(写测试、改 bug、加功能)。
> 你之前没有任何上下文。**本手册与具体任务无关,可反复套用。**
>
> **两条铁律**:① 大方向锁死,具体决策自己拍板,绝不停下来等人;② 收工前必须把知识
> 回写到文档,否则下一个会话将两眼一抹黑。

---

## 0. 上手(2 分钟,必做)

1. 读 `AGENTS.md`(本仓库唯一的会话入口)——命令、架构、不变量、测试约定。
2. 任务**碰到公开 API** → 读 `docs/SPEC.md`(API 唯一真源)。
3. 要写/改代码 → 读 `CONTRIBUTING.md`(架构深挖 + 加功能清单 + **文档同步约定**)。
4. 看 `git log --oneline -20` 和 `CHANGELOG.md` 顶部——**之前发生过什么**。

> 全量文档地图见 `docs/README.md`。拿不准读哪份就查它。

---

## 1. 讨论方案(先想清楚,再动手)

1. 用一两段话说清方案:改哪些文件、为什么、取舍是什么、影响哪些测试与不变量。
2. **等用户确认**(交互式会话)——不要跳过。
3. 确认后把方案落成产物:开分支 `git checkout -b <任务名>`,把方案写进分支首个 commit
   message,或写进 `docs/plans/<任务名>.md` 并提交。

> **无人值守会话例外**:用户明确说"无人看守、自己定夺"时跳过等待,但仍要把方案写进
> 分支/plan 文件(见 §4)。

---

## 2. 执行(按里程碑小步提交)

- 拆成 2–5 个里程碑,**每个里程碑结束就 `git commit`**(Conventional Commits:
  `feat:` / `fix:` / `test:` / `docs:` / `refactor:`)。黑客松验收要求"开发过程可追踪"。
- **每写完一段就 `moon check`,每个里程碑跑 `moon test`**——不攒未编译代码。
- 改公开签名 → 跑 `moon info` 并**提交重新生成的 `src/pkg.generated.mbti`**。

---

## 3. 卡住时的决策规则(保持前进,绝不停摆)

> **总原则:宁可缩小范围,不停摆,不自造一套偏离 SPEC 的设计。**

1. **编译错误** → 查 `docs/MOONBIT_REF.md`;常见坑是 trait 约束、`mut`/所有权、模式匹配、
   **结构体泛型不能带约束**。对照本仓库已有代码改,别凭记忆重写。
2. **语义不确定** → 以 `docs/SPEC.md` 为准;SPEC 没写清时以参考实现真实行为为准,
   并在 `CHANGELOG.md` 记一笔选择与理由。
3. **某测试卡 >15 分钟** → 先跳过并写 `// TODO: <原因>`,继续下一个;在 README "Known Issues"
   登记。**绝不让一个测试卡死整个里程碑。**
4. **某功能严重超时** → 砍到能用的最小子集,在 `CHANGELOG.md` 记"暂不支持 X(计划 vX.Y)"。
5. **SPEC 与参考实现矛盾且无法判断** → 选**更简单、更可测试、更符合"索引只是加速的视图"**
   直觉的那个,并在 CHANGELOG 记录。

**禁止**:为过测试而削弱不变量断言(I1–I8 是本库命根子);引入对 `aurasuisui/bimap` 或
`aurasuisui/indexmap` 的依赖。

---

## 4. 无人看守时:给自己装心跳

若用户明确"无人值守",防止误以为做完而 idle:

- **自我驱动(首选)**:每完成一个里程碑,排一个约 90 秒后的"自检并续跑下一项"。
- **周期兜底**:建周期自检任务,空闲时自动叫醒续跑(注意只在会话存活且空闲时触发)。

---

## 5. 收尾(知识回写,每个会话必做)

1. **同步文档**——按 `CONTRIBUTING.md` 的"文档同步约定"联动更新(SSOT 表 + 改动清单)。
2. **新增/删除了文档?** → 更新 `docs/README.md` 枢纽地图(防孤儿文件)。
3. **非显然决策** → 写进 `CHANGELOG.md` 的 "Notes / Deviations"。
4. 跑六步 CI 本地验证。
5. 工作区干净(`git status` 空),分支可发 PR。

---

## 6. 完成定义(通用)

- [ ] 六步 CI 全绿;`moon info` 后 `git diff --exit-code` 干净
- [ ] 新增/修改的测试覆盖改动;涉及不变量则已扩展 `check_invariants`
- [ ] 文档已按 §5 同步;`docs/README.md` 地图无孤儿
- [ ] `CHANGELOG.md` 记录了改动与关键决策
- [ ] git 历史清晰(每里程碑一提交)
