### 项目简介
MoonBit MultiIndex 提供一个「记录表 + 多个二级索引」的容器 `Table[K, V]`：同一批记录可按不同字段查找，索引分唯一/非唯一、哈希/有序四个象限；每条记录有稳定句柄 `RowId`（槽位 + 代际号），删除后槽位可复用，但过期句柄不会误命中新记录。MoonBit 现有的 Map 只能按一个键查找，IndexMap 解决保留插入顺序，BiMap 解决两个互为逆的唯一索引；本项目把 BiMap 推广为 N 个彼此独立的索引，并补上记录身份与非唯一索引。

### 通用性、场景与索引增删
项目属于基础数据结构方向。键与记录都是泛型参数；索引在运行时按名字增删：增用 `register_*`，删用 `unregister_index`，删后同名重注册会自动从现有记录回填；索引若因库外改动而脏，`rebuild_index`（本期新增）从当前记录一步重新推导，唯一键冲突时返回 `Err` 且旧索引逐项不变。索引不参与序列化，记录与索引解耦，便于持久化和跨进程传递。典型场景：内存表多路检索（邮箱/城市/积分）、配置项检索（名字/分组/优先级）、仿真实体索引（阵营/类型/耐久）；凡是「同一批数据要按多个字段反复查找」都可直接复用。

### 核心功能
- 记录存储与稳定句柄：`Table[K, V]`，`RowId` 由槽位与代际号组成，代际耗尽时槽位永久退役；
- 索引注册、删除与修复：四象限 `register_*`（非空表自动回填）+ `unregister_index`（只摘注册表，名字可重注册）+ 本期新增 `rebuild_index`（脏索引一步修复）；
- 写入：`insert` / `insert_many` / `update` / `modify` / `remove` / `swap_remove` / `clear`；唯一冲突时返回 `Err` 并归还记录（共享容器 Err 边界见 SPEC §3.7）；
- 查询：点查 `get` / `get_by`，遍历 `iter_by` / `iter_asc_by` / `iter_desc_by` / `range_by` / `range_half_open_by` / `iter`，另有本期新增的 `contains_by` / `count_by`（不物化桶）与 `first_by` / `last_by`（有序索引的键序两端）；降序遍历本期改为惰性（内部走 `SortedMap::rev_iter2`，不再物化全部桶，公开签名不变）；
- 一致性与可变记录契约：`verify_invariants` 返回首个违反点与位置，`index_stats` 给出桶分布；共享引用必须视为只读，改被索引字段走 `update` / `modify`；脏了用 `rebuild_index` **一步**恢复（仅唯一冲突失败时降级三步），见 SPEC §3.7；
- JSON 与质量：只序列化记录，载入后重新注册索引即可恢复；`moon test --target all` 共 **209** 条（wasm / wasm-gc / js / native 四后端各 209 条、全绿），`Table::*` 公开方法 **38** 个，CI 含零警告与格式门禁；工具链对齐 `moon 0.1.20261120`。

### 原创性与参考说明
本项目为原创实现，没有移植任何代码。设计上参考 Rust 的 multi_index_map（https://github.com/lun3x/multi_index_map，MIT 许可证）：结构同为「记录表 + 每索引一张查找表」，但本项目句柄带代际号（对方是裸下标）、索引在运行时注册（不用过程宏）、补上范围查询与公开一致性自检、唯一冲突整批拒绝并归还记录（不采用 first-wins）。第三方来源与许可证在仓库 NOTICE 中逐条登记。
