## 二、项目目标

提供一个 MoonBit 的**多级索引记录表**容器 `Table[K, V]`:存储记录,并在其上维护任意多条命名索引,
使同一批数据可以按不同字段 O(1) / O(log n) 检索。

## 三、已有基础与本期新增(重要)

- **已有基础**:作者在 MoonBit 生态已有 `aurasuisui/indexmap`(有序哈希表)与 `aurasuisui/bimap`
  (双向映射)两个已发布库,积累了哈希表引擎、删除不变量、对拍测试与差分夹具方法论。
- **本期新增**:**全新仓库、全新实现**。`moonbit-multiindex` 于 2026-10-14 立项,本项目不是既有
  项目的改名或包装 —— 它引入 bimap/indexmap 都不具备的两个概念:**记录身份**(`RowId`,槽位 + 代际号)
  与**非唯一索引**。定位关系为:`BiMap` = "2 个互为逆的唯一索引"的特例;本库泛化为 **N 个彼此独立的索引**。

## 四、技术方案

**数据布局**:记录存于 `rows : Array[V?]`(槽位 + 空洞),配 `gens`(代际号)、`free`(空闲槽)、
`order`(插入序),以及索引注册表 `indexes`。

**四象限索引**(唯一性 × 有序性):

| | 哈希 | 有序 |
|---|---|---|
| **唯一** | `Map[K, Int]` | `SortedMap[K, Int]` |
| **非唯一** | `Map[K, SortedSet[Int]]` | `SortedMap[K, SortedSet[Int]]` |

**索引条目只存槽位号**,值只在 `rows` 中存一份(单一真源);代际号只用于校验外部传入的句柄。

**一致性纪律**:所有变更汇聚到三个私有汇聚点(`insert_impl` / `remove_impl` / `modify_impl`),
并以 9 条不变量(I1–I9)为靶子持续校验,其中 `verify_invariants()` **作为公开 API** 暴露。

**正确性设计**(相对参考实现的增量):

1. **冲突零变更**:唯一性检查全部在变更之前完成,返回 `Err` 时表与调用前等价;并把记录原样归还调用方。
2. **`modify` 原子性**:先算新投影 → 逐唯一索引预检(排除自身)→ 全部通过后再统一落地。
3. **代际号溢出即退役槽位**:使陈旧句柄永不复活(Rust 参考实现均选择静默回绕)。
4. **绝不 panic**:所有冲突路径返回 `Result`。

**相对参考实现的差异化能力**:范围查询(`range_by` / `range_inclusive_by` / `iter_asc_by` / `iter_desc_by`)
为上游缺口;公开自检 API 亦为上游所无。

## 七、测试与质量保障

| 层次 | 手段 |
|---|---|
| 单元 | 注册 / 插入 / 查询 / 删除 / 更新矩阵 |
| 不变量 | `check_invariants`(I1–I9)在随机操作序列**每一步之后**校验 |
| 模型对拍 | 与 `Array[V]` 线性扫描朴素实现全操作序列差分 |
| 差分 | 对 Rust 参考实现的观测序列对齐,夹具由 `tools/diffgen` 生成并入库 |
| 白盒 | 直读私有字段校验 `free` 一致性、代际号单调性 |
| 回归 | 钉死设计探针发现的 `update` 冲突漏洞与 `modify` 原子性 |
| 压力 | 10k+ 操作、槽位复用风暴、长桶 |
| 基准 | 与线性扫描、手工多表维护对比 |
